# 🛒 E-Commerce Analytics Project (5-Day Plan)

An end-to-end **data analysis project** on synthetic e-commerce order data — built in 5 daily stages, from raw/dirty data generation to a final business-ready dashboard and report.

---

## 📅 5-Day Roadmap

| Day | Script | What it does |
|-----|--------|---------------|
| **Day 1** | `src/day1_generate_and_clean_data.py` | Generates a realistic (synthetic) orders dataset with intentional real-world messiness (duplicates, nulls, bad types, inconsistent casing), then cleans it |
| **Day 2** | `src/day2_eda.py` | Exploratory Data Analysis — revenue, orders, customers, category/city/product breakdowns, monthly trend |
| **Day 3** | `src/day3_visualizations.py` | Generates 5 charts: monthly revenue trend, revenue by category, top 10 products, payment method split, revenue by city |
| **Day 4** | `src/day4_customer_rfm_analysis.py` | RFM (Recency, Frequency, Monetary) customer segmentation — Champions, Loyal, At Risk, Lost, etc. |
| **Day 5** | `src/day5_dashboard_report.py` | Combines everything into one visual dashboard (PNG) + a final Markdown business report with recommendations |

│   └── reports/                        # CSV summaries + final_report.md

> Note: `data/` and `outputs/` are regenerated by running the scripts, so their contents are excluded via `.gitignore`. Only the code is meant to be version-controlled.

## ⚙️ Setup

```bash
# 1. Clone / open the project folder
cd ecommerce-analytics-project

# 2. (Recommended) create a virtual environment
python -m venv venv
source venv/bin/activate      # on Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt
```

---

## ▶️ How to Run

**Option A — run everything at once:**
```bash
python main.py
```

**Option B — run day by day (recommended for learning):**
```bash
python src/day1_generate_and_clean_data.py
python src/day2_eda.py
python src/day3_visualizations.py
python src/day4_customer_rfm_analysis.py
python src/day5_dashboard_report.py
```

Each script must run in order since later stages depend on the CSVs produced by earlier ones.

---

## 📊 Outputs

After running the full pipeline, you'll get:

- **`outputs/charts/`** — 5 individual charts + `full_dashboard.png` (combined 4-panel view)
- **`outputs/reports/`** — CSV breakdowns (revenue by category/city/product, RFM segments) and `final_report.md` (human-readable summary with recommendations)

---

## 🧠 Key Techniques Used

- Synthetic data generation with `numpy` / `pandas`
- Data cleaning: deduplication, missing-value imputation, type coercion, text normalization
- EDA: groupby aggregations, resampling for time trends
- Visualization: `matplotlib` + `seaborn` (bar, line, pie charts, multi-panel dashboard)
- Customer segmentation via **RFM analysis** with quartile-based scoring
